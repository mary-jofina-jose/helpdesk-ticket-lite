# Helpdesk Ticket Lite

A Power Platform mini project: raise IT tickets, route them to technicians,
track SLA deadlines, and capture user feedback.

## Built with
Dataverse, Power Apps (canvas), Power Automate, Power BI

- /HelpdeskTicketLite.zip  : unmanaged solution export
- /Helpdesk_Dashboard.pbix : Power BI report
